# SindhOS palette

Ajrak colours, used as accents (selection, focus, active indicators, the menu
button), never as whole surfaces of pattern.

| Name | Hex | Use |
|---|---|---|
| Ajrak red | `#9B1B1E` | accent on light surfaces: selection, buttons, close-button hover, dock indicator |
| Ajrak red, bright | `#C0393B` | accent on dark surfaces (better contrast) |
| Indigo | `#1F2A5A` | dark panels, boot screens, headings |
| Indigo, deep | `#161D40` | dark surfaces, gradients |
| Black | `#141414` | text on cream, outlines |
| Cream | `#F6F1E7` | light surfaces, text on indigo |

Light UI surfaces: window `#F8F7F4`, header `#EFEDE8`, text `#22232A`.
Dark UI surfaces (indigo-tinted): window `#191B26`, header `#212435`, text `#ECECF1`.
