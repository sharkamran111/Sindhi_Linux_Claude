سنڌي ڪيبورڊ رهنمائيSINDHI KEYBOARD GUIDE

How to switchٻولي ڪيئن مٽايو

Press Ctrl + Space to go to the next keyboard: English → Roman Sindhi → Sindhi → English. Alt + Shift goes back to the keyboard you used before.

Or click the language button in the taskbar, next to the clock.

Roman Sindhi: type words in English letters, sindhi boli gives سنڌي ٻولي. Press Space for the first suggestion or 1–9 for another.

Sindhi (this page): each key types one letter. Hold Shift for the second set of letters.

انگريزي، رومن سنڌي ۽ سنڌي جي وچ ۾ مٽائڻ لاءِ Ctrl + Space يا Alt + Shift دٻايو.

يا ٽاسڪ بار تي ٻوليءَ واري بٽڻ تي ڪلڪ ڪريو.

ٻين اکرن لاءِ Shift دٻائي رکو.
